# Legal Local Transcriber

Локальное веб-приложение для:

- транскрибации (WhisperX large-v3),
- выравнивания таймкодов,
- диаризации (Pyannote через WhisperX),
- юридической пост-обработки текста через Ollama (Qwen 2.5).

## Быстрый запуск

1. Скопируйте переменные окружения:

```bash
cp .env.example .env
```

2. Укажите `HF_TOKEN` в `.env`.
3. Запустите:

```bash
./start.sh
```

4. Откройте в браузере:

- локально: `http://127.0.0.1:8000`
- из LAN: `http://<IP_сервера>:8000`

## Что делает `start.sh`

- проверяет `python3`, `ffmpeg`, `ollama`,
- проверяет доступность Ollama API,
- проверяет наличие модели `qwen2.5` и при необходимости выполняет `ollama pull qwen2.5`,
- создает `.venv` (если нужно),
- ставит зависимости только при изменении `requirements.txt`,
- запускает FastAPI backend.
